# CLI examples

Sample input files for `stb solve` and `stb validate`.

## Quick start

From the project root (`stb_0_1`), with the virtual environment and `stb` installed:

```bash
.venv/bin/pip install -e .

# Smallest model (cantilever, 2 nodes, 1 element)
stb solve examples/cantilever.dat -o examples/cantilever.out -q -v

# Check input only
stb validate examples/cantilever.dat -v
```

Without installing `stb`:

```bash
.venv/bin/python -m stb_cli solve examples/cantilever.dat -o examples/cantilever.out -q
```

## Sample files in this folder

| File | Description |
|------|-------------|
| `cantilever.dat` | 2 m cantilever, fixed base, 5 kN at tip (load case 0) |
| `cantilever.out` | Example output (generated by `stb solve`; safe to delete and regenerate) |

## Input format

Full specification: **[docs/input_format.md](../docs/input_format.md)**

- **`PLOD`** — point load (nodal)
- **`ELOD`** — member distributed load
- **`ALOD`** — area load
- **`GLOD`** — gravity

**`LOAD` is not supported** (ambiguous; ignored if present in old files).

## What the output contains

Result files use the same text format as the GUI results window, for example:

- `NDSP` — nodal displacements
- `REAC` — support reactions (Tx, Ty, Tz in kN; Rx, Ry, Rz in kNm)
- `EFRC` — element end forces
