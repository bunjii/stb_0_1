# Structural Toolbox — 学生用（Mac・フォルダ版）

> **教員から .pkg / .dmg / Setup 用 tar.gz をもらった場合**は、こちらではなく [学生用_インストール_Mac.md](学生用_インストール_Mac.md) を読んでください。

プログラミングの知識は不要です。**Python の別途インストールも不要**です（配布物に同梱されています）。

---

## 用意するもの

- **macOS 11 以降**
- **インターネット**（初回セットアップ時のみ）
- **空きディスク** 約 500 MB

---

## 1. 配布ファイルを開く

1. 教員から受け取った `StructuralToolbox_Mac_Setup_YYYYMMDD.tar.gz` をダブルクリックして展開する。
2. 展開したフォルダを **書類** など、手元のディスクに置く。
3. 同じフォルダに次があることを確認する:
   - `インストール.command`
   - `payload` フォルダ

---

## 2. 初回だけ — インストール

1. **`インストール.command`** を右クリックして **開く**。
2. ターミナルの指示に従う（**5〜15 分**かかることがあります）。
3. 「インストールが完了しました」と出たら閉じてよいです。

このとき次のことが行われます（自動）:

- この Mac の CPU に合う **Python 3.12**（同梱）を使う
- ユーザー専用の **`.venv`** を作る
- Structural Toolbox 用ライブラリをインストールする
- アプリケーションフォルダとデスクトップに起動用アイコンを作る

**Mac にもともと入っている Python は使いません。**

右クリックで開けないとき:

```bash
bash インストール.command
```

---

## 3. 毎回の使い方

1. デスクトップまたはアプリケーションフォルダの **「Structural Toolbox」** を開く。
2. ブラウザが開いたら、モデルを選んで **Solve** する。
3. 終了するときは、ターミナルのウィンドウを閉じる。

インストール先の `payload` を直接使う場合は、コピー後のフォルダにある **`Start Structural Toolbox.command`** でも起動できます。

**ターミナルは解析中は閉じないでください。**

---

## 4. 最初に試すモデル

| モデル | 説明 |
| --- | --- |
| `examples/cantilever.dat` | 最も簡単な片持ち梁（まずこれで Solve） |

場所: `~/Library/Application Support/StructuralToolbox/examples/`

---

## 5. よくあるトラブル

| 症状 | 対処 |
| --- | --- |
| 「同梱の Python が見つかりません」 | tar.gz を展開し直す。`payload` の中に `python-standalone-arm64` または `python-standalone-x64` があること |
| ブラウザが開かない | もう一度起動する。`http://127.0.0.1:8765/` を手で開く |
| 「初回セットアップがまだ」 | インストール先の `Install_once.command` を実行 |
| インストール失敗 | インターネット接続を確認して、`インストール.command` を再実行 |
| Solve でエラー | 教員に `.dat` の行番号とメッセージを伝える |

---

## 6. やらなくてよいこと

- **python.org から Python をインストール**（配布物に含まれています）
- **`python-standalone-*` や `.venv` フォルダの削除**（削除すると再セットアップが必要）
