# Structural Toolbox — 学生用（Windows 11・ZIP 版）

> **教員から Setup.exe をもらった場合**は、こちらではなく [学生用_インストール_Windows.md](学生用_インストール_Windows.md) を読んでください（.bat は不要です）。

プログラミングの知識は不要です。**Python の別途インストールも不要**です（ZIP に同梱されています）。

---

## 用意するもの

- **Windows 11**（Windows 10 でも同様の手順で試せます）
- **インターネット**（初回セットアップ時のみ — ライブラリのダウンロード）
- **空きディスク** 約 500 MB（解凍後 + 初回セットアップ後）

---

## 1. 配布 ZIP の解凍

1. 教員から受け取った ZIP（例: `StructuralToolbox_Windows_20260604.zip`）を解凍する。
2. **ローカルディスク**（`C:\Users\...\Documents` など）に置く。Dropbox 直下は同期の競合を避けるため非推奨。
3. 次のものが **同じフォルダの直下** にあることを確認する:
   - `Install_once.bat`
   - `Start Structural Toolbox.bat`
   - `python-embed` フォルダ（同梱 Python）
   - `examples` フォルダ

**注意:** ZIP の中に `StructuralToolbox_Windows_...` のようなフォルダが 1 段入っていることがあります。その **中** で `.bat` を実行してください。

---

## 2. 初回だけ — セットアップ

1. **`Install_once.bat`** をダブルクリックする。
2. 黒い画面に文字が流れる（**5〜15 分**かかることがあります）。
3. 「セットアップ完了」と表示されたら、何かキーを押して閉じる。

このとき次のことが行われます（自動・操作不要）:

- 同梱の **Python 3.12**（`python-embed`）を使用
- このフォルダ専用の **`.venv`** を作成
- Structural Toolbox 用ライブラリをインストール

**PC にもともと入っている Python は使いません。** 他の授業用 Python と混ざりません。

---

## 3. 毎回の使い方

1. **`Start Structural Toolbox.bat`** をダブルクリックする。
2. しばらくすると **ブラウザ**（Chrome / Edge など）が開く。
3. 画面上部で **モデル（.dat）** を選び、**Solve** で解析する。
4. **Results** タブで変形・部材力などを確認する。
5. 終了するときは、黒い画面で **Ctrl+C** を押すか、その画面を閉じる。

**黒い画面は解析中は閉じないでください。**

---

## 4. 最初に試すモデル

| モデル | 説明 |
| --- | --- |
| `examples/cantilever.dat` | 最も簡単な片持ち梁（まずこれで Solve） |
| `examples/` 内のその他 | 教員が指定したファイル |
| `data/` 内 | 授業用の大きいモデル（教員指示に従う） |

---

## 5. 課題ファイルの置き場所

- 教員から `.dat` をもらったら、ZIP を解凍したフォルダ内の `examples` などにコピーする。
- 一覧に出ない場合は **Start を一度終了**してから再起動する。

---

## 6. よくあるトラブル

| 症状 | 対処 |
| --- | --- |
| 「同梱の Python が見つかりません」 | ZIP を再解凍。`python-embed` フォルダがある階層で実行 |
| ブラウザが開かない | `Start` を再実行。`http://127.0.0.1:8765/` を手で開く |
| 「初回セットアップがまだ」 | `Install_once.bat` を実行 |
| インストール失敗 | インターネット接続を確認し、`Install_once.bat` を再実行 |
| `No module named venv` | 古い ZIP の可能性あり。教員から新しい ZIP を入手し、フォルダごと入れ替えて `Install_once.bat` を再実行 |
| Solve でエラー | 教員に `.dat` の行番号とメッセージを伝える |
| ウイルス対策がブロック | 教員に相談（フォルダの除外設定など） |

---

## 7. やらなくてよいこと

- **python.org から Python をインストール**（ZIP に含まれています）
- **Git** やコマンドの手入力
- **`python-embed` や `.venv` フォルダの削除**（削除すると再セットアップが必要）
