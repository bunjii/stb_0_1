# ASTIM計算書PDFとの差分整理

この文書は、ASTIM相当の確認申請用計算書PDFの章立てに対して、Structural Toolbox の現状出力、木造平屋MVPで対応する範囲、MVPでは対象外または手作業確認にする範囲を固定するための差分表です。

## 前提

- 対象は、直近MVPでは木造平屋の確認申請補助計算書ドラフトに限定する。
- 完全な確認申請書式の自動生成ではなく、提出前チェックと設計者確認に使える Markdown/HTML/PDF 化しやすい中間成果物を目標にする。
- 既存の `.dat` と `.out` は低レベル解析入出力として維持し、建物情報・通り・層・部材分類・帳票設定は `model.project.json` で補う。
- 法規適合、審査機関ごとの様式差、手入力した設計条件の妥当性は、設計者が最終確認する。

## 状態区分

| 状態 | 意味 |
| --- | --- |
| `現状出力` | 既存の `.out`、CLI、GUI、または `model.project.json` で既に根拠データを保持・表示できる |
| `MVP対応` | 木造平屋MVPで帳票項目として出す |
| `MVP一部対応` | 表・代表値・手入力条件など、限定した形で出す |
| `手作業確認` | MVPでは入力欄、未対応一覧、または外部資料への参照として扱い、設計者が補う |
| `対象外` | 木造平屋MVPでは扱わない |

## 現状出力の棚卸し

| 種別 | 現状の出力・入力 | 帳票化で使える内容 | 不足している意味付け |
| --- | --- | --- | --- |
| 解析結果 | `.out` の `NDSP`, `REAC`, `EFRC`, `SPRP`, `MSTR` | 節点変位、支点反力、部材端応力、断面性能、膜要素応力 | 荷重種別、部材分類、章立てに沿った表題・単位説明 |
| 解析入力 | `.dat` の `MATE`, `SECT`, `NODE`, `ELEM`, `CONS`, `PLOD`, `ELOD`, `ALOD`, `GLOD`, `LNME`, `LCMB` | 材料、断面、節点、部材、支点、荷重ケース、荷重組合せ | 建築用途、通り、層、木材等級、荷重根拠、検定条件 |
| GUI | モデル表示、変形・応力・荷重の可視化 | モデル確認、スクリーンショットによる補助図 | 申請用図面、縮尺、図面注記、章別出力 |
| プロジェクト定義 | `model.project.json` の建物情報、通り、層、部材分類、帳票設定 | 表紙、一般事項、通り・層、部材用途、帳票モード | 荷重根拠表、偏心率計算入力、断面検定条件、適用範囲チェック |

## 章別ギャップマップ

| ASTIM章 | 要求される主な内容 | 現状出力 | 木造平屋MVPでの扱い | MVP対象外・手作業確認 |
| --- | --- | --- | --- | --- |
| §1 一般事項・略伏図・略軸組図・断面リスト | 表紙、建築物概要、設計者、略伏図、略軸組図、部材リスト | `model.project.json` で建物情報と部材分類を保持できる。GUIで3Dモデル確認はできる。`SPRP` で断面性能は出る。 | 表紙、一般事項、構造設計概要、木材・断面・面材の一覧を出す。図面は簡易モデル図または表で代替する。 | 申請図面品質の略伏図・略軸組図、接合金物リスト、基礎詳細図、CLTリストは手作業確認または対象外。 |
| §2 設計方針・準拠規準・使用材料 | 構造設計方針、準拠基準、計算ルート、使用材料、許容応力度 | `pyproject.toml` と CLI でプログラム情報は確認できる。`.dat` の `MATE`/`SECT` に材料・断面の低レベル情報がある。 | 定型文と `model.project.json` から設計方針、準拠基準、計算ルート、使用材料表を出す。 | 木材の全許容応力度、使用環境係数、長期短期係数の網羅的な自動算定は後続対応。MVPでは根拠値を手入力確認する。 |
| §3 プログラム使用状況・チェックリスト | 使用プログラム、警告、注意、エラー、適用範囲チェック | CLI/GUIの実行ログと例外はあるが、帳票用の警告分類はない。 | 木造平屋MVPの適用範囲、未対応項目、手作業確認項目、解析時警告を一覧化する。 | 審査機関様式に完全一致するチェックリストは対象外。 |
| §4 荷重・外力 | 固定荷重、積載荷重、積雪、風、地震力、荷重ケース | `.dat` の `PLOD`/`ELOD`/`ALOD`/`GLOD`、`LNME`、`LCMB` で解析荷重は入力できる。 | 固定・積載・積雪・風・地震の条件表を `project` 側で持ち、解析荷重ケースとの対応表を出す。建物重量と地震力は代表値・集計表から追跡できる形にする。 | 地域条件からの積雪・風圧・地震力の完全自動算定、受圧面積の自動拾いは対象外。 |
| §5 準備計算 | 剛性条件、CMQ、節点重量、重量集計 | 解析モデル内部には剛性、荷重、支点反力がある。帳票用の節点重量表はない。 | モデル化条件、荷重ケース条件、節点重量または層重量の集計表を出す。CMQは応力表で代替する。 | CMQ図、詳細な重量拾い図、複数層の汎用重量分配は後続対応。 |
| §6 応力解析 | 架構モデル、支点条件、応力図、変位図、反力図、応力表 | `NDSP`、`REAC`、`EFRC`、GUI表示で節点変位・反力・部材応力・変形表示を確認できる。 | 解析モデル概要、通り・層・支点条件表、最大変位表、反力表、部材応力表を帳票整形する。 | 申請用の応力図・変位図・反力図、通り別の詳細図面出力は後続対応。 |
| §7 断面検定 | 木造柱、梁、筋かい、接合金物、検定比、応力組合せ | `EFRC` と `SPRP` から検定に必要な応力・断面性能の一部は得られる。検定ロジックは未実装。 | 木造梁・柱の基本検定を優先し、検定用応力組合せ、許容値、割増率、NG/OK/未対応を一覧化する。 | 筋かい、接合金物、面材、基礎梁の網羅的検定は手作業確認または対象外。 |
| §9 層間変形角・剛性率 | 最大層間変形角、柱の層間変形角、剛性率 | `NDSP` で節点変位は出るが、層定義と代表点の扱いは既存 `.dat` だけでは不足する。 | 平屋の代表高さと代表変位から最大層間変形角を算定し、根拠節点を明示する。 | 剛性率、複数階の層間変形角、柱ごとの詳細判定は対象外または後続対応。 |
| §10 偏心率 | 重心、剛心、偏心距離、弾力半径、偏心率、構面別剛性 | 現状出力なし。通り・層・部材分類は `model.project.json` で保持できる。 | 入力値と解析結果から追跡できる重心・剛心・偏心率の中間表を出す。構面別剛性はMVPで必要な範囲に限定する。 | 複雑な剛床判定、複数階、任意形状建物の完全自動偏心率計算は対象外。 |
| §12 基礎・地盤 | 基礎概要、地耐力、基礎盤、基礎梁、転倒 | `REAC` で支点反力は出る。基礎・地盤検定は未実装。 | 反力表を基礎検討用の根拠として出し、基礎概要は定型文または手入力欄にする。 | 地耐力、基礎盤、RC基礎梁、配筋、転倒検討の自動判定は対象外。 |
| §14 総合所見 | 総合判定、未対応項目、注意事項 | 現状なし。 | OK/NG/未対応/手作業確認項目を集約した所見ドラフトを出す。 | 法的な最終判定文、審査機関ごとの表現調整は設計者確認。 |

## MVPで最初に出す帳票構成

1. 表紙・一般事項
2. 設計方針・準拠基準・使用材料
3. 部材リスト
4. 荷重条件表
5. 解析モデル概要
6. 解析結果表
7. 重心・剛心・偏心率
8. 木造梁・柱の基本断面検定
9. 警告・注意・未対応項目一覧
10. 総合所見ドラフト

## 次の実装単位

1. `model.project.json` に荷重条件表、適用範囲、手作業確認項目を持たせる。
2. `.out` の `NDSP`/`REAC`/`EFRC`/`SPRP` を帳票用の中間データに変換する。
3. `stb_reports/` を追加し、Markdown形式の計算書ドラフトを生成する。
4. 偏心率と木造梁・柱検定の計算根拠表を、帳票内で追跡可能な形にする。
